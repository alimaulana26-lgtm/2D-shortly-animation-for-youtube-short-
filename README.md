# SHORTLY — 2D Explainer Starter

Starter project animasi 2D sederhana untuk channel YouTube Shorts SHORTLY.

## Isi proyek
- `index.html` — struktur panggung animasi.
- `style.css` — karakter, background, dan gerakan CSS.
- `script.js` — urutan adegan sederhana.
- `assets/` — tempat menyimpan gambar/audio tambahan.

## Menjalankan di HP
1. Ekstrak ZIP ini.
2. Buka folder `shortly-animation-starter`.
3. Buka `index.html` menggunakan browser seperti Chrome.
4. Tekan **Putar animasi** untuk menjalankan demo.

Jika browser Android tidak membuka file lokal dengan benar, unggah folder ini ke GitHub lalu aktifkan GitHub Pages.

## Mengunggah ke GitHub
1. Masuk ke https://github.com/ dan login.
2. Tekan tombol **New repository**.
3. Isi nama: `shortly-animation-starter`.
4. Pilih **Public** atau **Private**, lalu buat repository.
5. Pilih **Add file → Upload files**.
6. Unggah isi folder ini (bukan file ZIP-nya), lalu commit.

## Mengaktifkan GitHub Pages
1. Buka repository → **Settings**.
2. Pilih **Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/ (root)`, lalu **Save**.
5. Tunggu proses publikasi. GitHub akan menampilkan alamat situs.

## Mengembangkan animasi
Minta Claude mengedit `index.html`, `style.css`, dan `script.js` secara bertahap. Beri instruksi agar desain karakter tetap konsisten. Jangan masukkan API key atau kata sandi ke repository.


## Cerita aktif
Versi ini menggunakan cerita **Doorway Effect** (lupa tujuan setelah masuk ke ruangan). Naskah dan durasi adegan diatur melalui `scenes.js`.
